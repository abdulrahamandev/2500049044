# Hospital Patient Information System

A simple React app for viewing sample patient IDs, names, assigned doctors, and appointment times. Search by patient name, ID, or doctor.

## Run locally

1. Install Node.js.
2. From this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create a production build in `dist`.

The dashboard uses fictional sample data and does not connect to a patient database.
